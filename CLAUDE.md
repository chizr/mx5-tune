# MX-5 NB turbo tune — notes for Claude Code

Chris's NB1 MX-5 (built 1.8 BP, **stock pistons**, forged rods, TD04HL-19T, ME442 ECU, 98 RON). This repo holds the ECU calibration, logs and the worklog. Read `docs/worklog.md` first: hardware, change log, findings, open items and reference numbers all live there.

## Layout

- `calibrations/mx5_nb_me442.mecal` — the one calibration file. History and versions are git commits and tags (`v1` original … `v7`). Don't create `_v8` copies; commit and tag instead.
- `logs/` — ECU logs, renamed `YYYY-MM-DD_HHMM_<source>_<what>.csv`. Index them in `logs/README.md` (calibration tag in the car, fuel age, what was tested).
- `docs/worklog.md` — the living record. `docs/run-sheet_vN.pdf` — printable test plan, generated by `tools/make_runsheet.py`.
- `tools/mecal.py` — read, diff and edit .mecal files. `tools/logtools.py` — load and analyse logs.

## Rules for calibration edits

1. Edit only through `tools/mecal.py` (`set_param`, `set_cells`, `save`). It replaces values as text and keeps every other byte, including CRLF line endings. Never re-serialise the XML or reformat the file.
2. Before committing, run `python3 tools/mecal.py diff <previous> <new>` and check that only the intended values changed. Report that diff to Chris.
3. One logical change set per commit, tagged `vN`. Add rows to the change log table in `docs/worklog.md` in the same commit (tag, area, setting, before, after, why).
4. Chris burns calibrations himself in MEITE after spot-checking. Never claim a version has been driven until he says so.
5. Some driver settings repeat a name: `EPS: Oil` has two `Enabled` params (temperature, then pressure → `occurrence=1`).
6. 2D tables are flat, row-major: index = row × cols + col. Rows are load (MAP kPa, `input_1`), columns are rpm (`input_0`).

## Safety stance

- Stock pistons: failures are ring lands from detonation. Low-rpm, high-load knock is the main risk; cylinders 2 and 3 already show a knock-like pattern on boost.
- Don't raise boost targets or add timing without log evidence. Prefer removing timing over adding it. Keep over-boost cut, lean, oil and knock protection enabled.
- Treat numbers from forums or guesses as approximate and label them. Recommend dyno with det cans for final timing.
- Road testing: full-throttle pulls belong on a closed road, track or dyno.

## Working with logs

- Load with `tools/logtools.load()` (pandas `index_col=False`; data rows end with a trailing comma and PC-log headers have leading spaces).
- 10 Hz typical. Useful commands: `logtools.py summary|lambda|knock|idle LOG`.
- Per-cylinder knock: compare each cylinder against its own light-load baseline (`knock` command), never raw levels between cylinders, because the single sensor hears cyl 2/3 loudest.
- Idle duty includes adders: primary fan +2% (3 s after fan on), power steering switch +6%. Check fan status before comparing idle points.
- Fuel pressure channel is gauge pressure: fuel − (MAP − 100) should be ~300 kPa.
- Ignore VVT channels (NB1 has no VVT) and EGT (no sensor fitted).

## Working style

Chris wants to understand cause and effect, not just get numbers. Explain why a change should help and what log signature would confirm it. Keep changes small and testable before the dyno.
